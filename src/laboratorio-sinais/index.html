Como coletar e salvar

Escolha o sinal, levante a mão direita, faça o sinal uma vez e abaixe a mão até ela sair da câmera. Repita de 15 a 20 vezes por sinal, variando velocidade e posição, de preferência com mais de uma pessoa. Se um exemplo sair errado, use Desfazer último.

Exporte antes de fechar ou recarregar. Para a página já abrir com os exemplos, copie o arquivo exportado para public/sinais-exemplos.json e publique novamente.

Como o reconhecimento decide

Cada sinal feito é comparado com todos os exemplos por DTW, que alinha movimentos mesmo quando um é mais rápido que o outro. Os k exemplos mais parecidos votam.

O sinal só vale se ficar abaixo do limite de distância, se a maioria dos vizinhos concordar e se a mão se mexer pelo menos um pouco como nos exemplos (punho parado não vira “sim”). O limite é recalculado a partir dos exemplos sempre que você entra em Testar; deixe vazio para não usar limite.

Avaliar a base testa cada exemplo contra os outros. Para medir de verdade, faça sinais novos aqui e anote os acertos. Expressão facial não é considerada neste protótipo.
